## Fontes do projeto

Este site usa fontes locais via `@font-face` em `styles.css`.

### Onde colocar

Coloque os arquivos de fonte nesta pasta (`assets/fonts/`) com **estes nomes**:

- `Proxima Nova Regular.ttf`
- `Proxima Nova Semibold.ttf`
- `Proxima Nova Bold.otf`
- `Proxima Nova Extrabold.ttf`

### Observações

- Se algum arquivo não existir, o navegador vai usar as fontes de fallback definidas no CSS.
- Se você preferir outros nomes de arquivo, atualize os caminhos dentro de `styles.css` nos blocos `@font-face`.
