# Oroz Eventos

Site estático de uma página (HTML/CSS/JS).

## Como abrir

- Abra `index.html` no navegador, ou
- Rode um servidor local simples (recomendado):

```bash
python3 -m http.server 5173
```

Depois acesse `http://localhost:5173`.
